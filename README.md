## Descripción

Proyecto académico para desarrollar una aplicación web con React y TypeScript que permita consultar personajes de Dragon Ball mediante una API pública. La aplicación contemplará un listado de personajes, búsqueda por nombre, consulta de detalles y gestión de favoritos persistentes.


## API utilizada

**API seleccionada:** Dragon Ball API.

- Documentación: https://web.dragonball-api.com/documentation
- Listado de personajes: https://dragonball-api.com/api/characters
- Ejemplo de detalle: https://dragonball-api.com/api/characters/1

## Requerimientos y tecnologías

Tecnologías previstas para la implementación:

- Node.js y npm, en versiones compatibles con la versión de Vite utilizada.
- React y TypeScript.
- Vite con la plantilla `react-ts`.
- HTML y CSS propio o CSS Modules.
- `fetch` para las peticiones HTTP.
- `localStorage` para conservar los favoritos.
- Git para el control de versiones y GitHub para alojar el repositorio.

## Instalación y ejecución


### 1. Clonar el repositorio


```bash
git clone https://github.com/jvalenciasolucinessof/ELECTIVA1_SOFTWARE_DRAGON_BALL_API_EL_SOLO.git
```

### 2. Entrar en la carpeta del proyecto

```bash
cd ELECTIVA1_SOFTWARE_DRAGON_BALL_API_EL_SOLO/db-api
```

### 3. Instalar las dependencias

```bash
npm install
```

### 4. Ejecutar en modo de desarrollo

```bash
npm run dev
```
### 5. Compilar el proyecto

```bash
npm run build
```
